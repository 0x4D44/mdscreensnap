# Code Review Report - mdscreensnap
**Date:** 2025.12.06
**Project:** mdscreensnap v0.1.0
**Reviewer:** Claude Code
**Files Reviewed:** 5 files, 1343 lines of code (primary)

## Executive Summary

mdscreensnap is a well-crafted Rust CLI tool for capturing screenshots on Windows and WSL. The code demonstrates strong Rust idioms, comprehensive testing (81% coverage), and thoughtful cross-platform handling. The single-file architecture is clean and maintainable for the current scope.

**Overall Assessment:** GOOD with room for improvement

**Strengths:**
- Excellent test coverage and organization
- Clean API design with clap
- Robust platform detection and handling
- Good error handling with anyhow
- Strong documentation

**Key Concerns:**
- Potential command injection vulnerabilities in PowerShell script generation
- Resource cleanup error handling could be improved
- Some code duplication across platform implementations
- Path escaping edge cases need hardening

## 4. Security Analysis

### Rating: MEDIUM (Needs Attention)

#### Critical Concerns

**🔴 CRITICAL: Command Injection Risk - PowerShell Script Generation**

**Location:** Lines 438-529 in `generate_powershell_script_with_monitor()`

**Issue:** Path escaping may be insufficient for all edge cases:

```rust
let escaped_path = windows_path.replace('\\', "\\\\").replace('\'', "''");
```

This only escapes backslashes and single quotes. PowerShell has many special characters that could break out of the string context.

**Attack Scenarios:**

1. **Backtick escape sequences:**
   ```
   path: C:\test`nWrite-Host "Injected"`.png
   ```

2. **Variable expansion in double quotes:**
   If script uses double quotes anywhere, `$variable` could be expanded

3. **Newline injection:**
   ```
   path: C:\test
   malicious-command
   .png
   ```

**Current Code:**
```rust
$bitmap.Save('{}', [System.Drawing.Imaging.ImageFormat]::Png)
```

Using single quotes is good (prevents variable expansion), but backticks and newlines could still break the script.

**Recommendation:**

```rust
fn escape_powershell_path(path: &str) -> Result<String> {
    // Validate path doesn't contain newlines or other control characters
    if path.contains(&['\n', '\r', '\0', '`'][..]) {
        bail!("Path contains invalid characters");
    }

    // For paths in single-quoted strings, only ' needs escaping to ''
    // But we should also validate the path looks reasonable
    let escaped = path.replace('\'', "''");

    // Validate the path looks like a real path
    if !escaped.ends_with(".png") {
        bail!("Output path must end with .png");
    }

    Ok(escaped)
}
```

Or better yet, use a PowerShell parameter-based approach:

```rust
fn generate_powershell_script_with_monitor_safe(
    windows_path: &str,
    monitor: &MonitorSelection,
) -> String {
    // Instead of embedding the path in the script,
    // pass it as a parameter to avoid injection entirely
    let script = match monitor {
        MonitorSelection::Primary => r#"
param([string]$OutputPath)
Add-Type -AssemblyName System.Windows.Forms
Add-Type -AssemblyName System.Drawing

$screen = [System.Windows.Forms.Screen]::PrimaryScreen
$bounds = $screen.Bounds
$bitmap = New-Object System.Drawing.Bitmap($bounds.Width, $bounds.Height)
$graphics = [System.Drawing.Graphics]::FromImage($bitmap)
$graphics.CopyFromScreen($bounds.Location, [System.Drawing.Point]::Empty, $bounds.Size)

$bitmap.Save($OutputPath, [System.Drawing.Imaging.ImageFormat]::Png)

$graphics.Dispose()
$bitmap.Dispose()
"#,
        // ... other cases
    };

    // Then execute with: -Command $script -OutputPath $path
    script.to_string()
}
```

```rust
pub fn is_wsl() -> bool {
    if cfg!(windows) {
        return false;
    }

    if let Ok(content) = fs::read_to_string("/proc/version") {
        let is_wsl = check_wsl_from_proc_version(&content);
        if std::env::var("DEBUG").is_ok() {
            eprintln!("WSL detection via /proc/version: {}", is_wsl);
        }
        if is_wsl {
            return true;
        }
    }

    let has_interop = check_wsl_interop_exists();
    if std::env::var("DEBUG").is_ok() {
        eprintln!("WSL detection via interop: {}", has_interop);
    }
    has_interop
}
```
